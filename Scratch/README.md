# Scratch

Working files only: drafts in progress, exports waiting to be reviewed, backups taken before a risky change, anything that has no permanent home yet. Git ignores everything here except this README, and search tools skip it.

- Finished work moves to its home (an area, a project, `Knowledge/`) or is deleted.
- `python3 scripts/check.py` lists anything untouched for 90 days; file it or delete it then.
- Agents move things here instead of deleting them (`AGENTS.md` §4).
