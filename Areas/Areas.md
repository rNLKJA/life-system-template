# Areas

The backbone of the vault: one folder per ongoing responsibility, each with a hub note marked `type: area`. An area has a standard to keep, not an end date. A project that serves an area carries `area:` in its hub note, so it shows in that area's backlinks and in the table below. Papers sit in each area's `Records/`, which git never syncs.

Add an area with `python3 scripts/new-area.py "Name" --records`.
