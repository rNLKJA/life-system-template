# Projects

Time-bound work with a finish line. Each project has a hub note (goal, scope and the `area:` it serves), `TASKS.md` (always exactly one next action), `MEMORY.md` (where it stands) and `LOG.md` (what happened). The live list is [[Projects/MEMORY|MEMORY]].

Start one with `python3 scripts/new-project.py "Name" --area "Area"`. A project that is done, or paused for 90 days, moves to `Archive/Projects/`.
