# Resources

Reference material loaded on demand: note templates, the project kit, and the guides that explain how this system works.

- `Resources/templates/`: one template per kind of note (Obsidian: Templates, Insert template).
- `Resources/project-template/`: the kit `scripts/new-project.py` copies.
- `Resources/system/`: how to write `AGENTS.md`, where memory and logs go, how the Obsidian graph stays lean, and how skills find the right folders.
