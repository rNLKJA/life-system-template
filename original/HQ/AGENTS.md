# HQ: AGENTS.md

Folder rules for `HQ/`. The root `AGENTS.md` governs; this file adds only what is specific here.

- **Goals** live in `goals.md`. A goal is specific and checkable: not "get fitter" but "run 5 km in under 30 minutes by June".
- **Reviews** (monthly, quarterly, yearly) ask three things: what went well, what did not, and the one change that would make the next period better. Save each as `YYYY-MM-DD Review.md` in this folder.
- **Role homes** (`Donna/`, `Ray/`) belong to their roles. Each holds the role's `MEMORY.md` and `LOG.md`; other agents read them but do not write there.
- **The intake** (`Intake/`) is not agent-writable. Papers are filed out of it by moving them, at the weekly review.
